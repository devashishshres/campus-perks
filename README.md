# campus-perks

A Cubbie Skill that finds free student software and learning tools, checks the terms on official pages,
and tracks claims, renewals and new offers. Built for Track 1 of the Cubbie Hackathon.

## Install

Text this repository's link to Cubbie and reply "yes" when it asks.

## Try it

- "What free software can I get as an ASU student?"
- "I claimed the GitHub pack."
- "Check every week for new student offers."
